# CircuitWorks

> **Design circuits. Build machines. Engineer your own solutions.**

CircuitWorks is a Minecraft technology mod centered around **electronics, circuit design, automation, and custom-built machines**.

Instead of simply crafting a machine that already knows what to do, CircuitWorks gives you the tools to **engineer how the machine works**.

## The Idea

The core philosophy of CircuitWorks is:

**Machines should be designed, not just crafted.**

Players will be able to create electronic circuits using components such as:

* Resistors
* Capacitors
* Diodes
* Transistors
* Voltage regulators
* Relays
* Sensors
* Controllers
* Microcontrollers

These circuits can then be used to control power, process signals, read sensors, drive motors, and eventually become the brains of custom machines.

## Electronics

Circuits will interact with electrical properties such as:

* Voltage
* Current
* Power
* Load
* Efficiency
* Heat
* Overload

The goal is not to create a perfect electrical engineering simulator, but a system that is **logical, consistent, and rewarding to understand**.

Good circuit design should matter.

## PCB Design

PCBs will be one of the core systems of CircuitWorks.

Players will be able to configure and assemble circuits inside a PCB interface.

For example:

```text id="3jqh2u"
12V Input
    ↓
   Fuse
    ↓
Voltage Regulator
    ↓
 Capacitor
    ↓
 5V Output
```

Different circuit designs may produce different results in terms of efficiency, maximum current, heat generation, and reliability.

## Custom Machines

Eventually, circuits will become part of modular machines.

```text id="y8wj9x"
Machine Chassis
      +
     Motor
      +
    Sensor
      +
 Control PCB
      ↓
 Custom Machine
```

The components and electronics installed inside the machine will determine how it behaves.

This allows different players to solve the same problem using completely different designs.

## Planned Systems

CircuitWorks is currently planned around three main systems:

### Power

Generation, distribution, conversion, and consumption of electrical energy.

### Signals

Analog signals, digital signals, pulses, sensors, and logic.

### Control

Electronic controllers capable of automating machines and interacting with the world.

## Development Status

🚧 **Early concept / development stage**

Initial development will focus on the foundations of the mod:

* Electrical system
* Voltage and current
* Basic electronic components
* PCB system
* Circuit behavior
* Simple powered devices

More advanced automation, sensors, controllers, and modular machines will be introduced progressively.

## Philosophy

CircuitWorks should make the player feel like an engineer without requiring an electrical engineering degree.

The focus is on:

* Experimentation
* Problem solving
* Circuit design
* Automation
* Optimization
* Building your own solutions
