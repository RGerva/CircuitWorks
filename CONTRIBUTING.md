# Contributing to CircuitWorks

Thank you for your interest in contributing to CircuitWorks!

CircuitWorks is currently in early development, so systems, APIs, mechanics, and project structure may change frequently.

Contributions, suggestions, bug reports, and discussions are welcome.

## Before Contributing

Before starting significant work, consider opening an issue or discussion describing what you would like to implement.

This helps avoid duplicated work and ensures that the proposed change fits the direction of the project.

Small fixes may be submitted directly through a pull request.

## Development

When contributing code:

* Keep changes focused and reasonably small.
* Follow the existing project structure and coding style.
* Prefer clear and maintainable code over unnecessary complexity.
* Avoid unrelated refactoring in feature or bug-fix pull requests.
* Document important or non-obvious behavior.
* Test your changes before submitting them.

## Pull Requests

Pull requests should clearly explain:

* What was changed.
* Why the change was necessary.
* How the feature or fix works.
* How the change was tested.

If the pull request implements or fixes a GitHub issue, reference the issue in the pull request description.

## Issues

When reporting a bug, include as much relevant information as possible, such as:

* CircuitWorks version
* Minecraft version
* Mod loader version
* Steps to reproduce
* Expected behavior
* Actual behavior
* Relevant logs or crash reports

For feature requests, explain the problem or use case before describing the proposed solution.

## Project Philosophy

CircuitWorks is built around a central idea:

> **Machines should be designed, not just crafted.**

New features should ideally reinforce the core pillars of the mod:

* Electronics
* Circuit design
* Engineering
* Experimentation
* Automation
* Modular machines
* Player-created solutions

CircuitWorks should provide meaningful engineering decisions without becoming unnecessarily difficult to understand or use.

The goal is not perfect real-world electrical simulation.

The goal is a system that is **logical, consistent, deep, and fun**.

## Code License

By contributing source code to CircuitWorks, you agree that your contributions may be distributed under the project's **MIT License**.

## Asset Contributions

Textures, models, sounds, artwork, icons, and other non-code assets are not covered by the MIT License.

By submitting an original asset and having it accepted into CircuitWorks, you agree that it may be distributed as part of the CircuitWorks project under the terms described in `ASSETS_LICENSE.md`.

Do not submit assets copied from other mods, games, websites, resource packs, or other sources unless their license explicitly permits their use in CircuitWorks.

## AI-Generated Contributions

Contributors are responsible for ensuring that submitted code and assets can legally be included in the project, regardless of the tools used to create them.

Do not submit generated content derived from copyrighted material that you do not have permission to use.

## Respectful Collaboration

Keep discussions constructive and focused on improving the project.

Technical disagreement is welcome. Personal attacks, harassment, and hostile behavior are not.
